# أنسب ⭐ (Anseb)

إضافة Stremio تختار أنسب نسخة وتربطها بأنسب ترجمة. الخادم نفسه يعرض صفحة الإعدادات، فلا يوجد بحث ولا واجهة منفصلة.

## النشر (Render)
Root Directory = الجذر (اتركه فارغاً) — Build: `true` — Start: `node backend/server.js`
(أو استخدم `render.yaml`). متغير اختياري: `PUBLIC_URL` إذا كان الرابط العام يختلف عما يراه الخادم.

افتح رابط الخدمة ← اضبط الإعدادات ← «تثبيت في Stremio».
زر Configure داخل Stremio يعيد فتح الصفحة بإعداداتك محمّلة.

## مصادر النسخ
Torrentio (يُضبط تلقائياً بمفتاح الديبرد، أو الصق رابطك المخصص)، Comet، StremThru: افتح صفحة إعدادهم من الأزرار، وانسخ رابط manifest والصقه. الصفحة تتحقق منه فوراً.

## مصادر الترجمة
- **SubDL**: مفتاح API.
- **SubSource**: مفتاح API (الملف الشخصي ← API Key).
- **OpenSubtitles.com**: مفتاح API + اسم المستخدم وكلمة المرور للتنزيل.
- **OpenSubtitles v3**: بدون مفتاح.
أزرار «اختبار» في الصفحة تتأكد من كل مفتاح.

## الإصدار 3: دقة أعلى
المطابقة صارت بثلاث طبقات:
1. **اسم النسخة**: مجموعة الإصدار، المصدر، الدقة، الترميز، الحلقة، السنة، النسخة الممدودة، و**منصة البث** (NF ≠ AMZN) و**الـ fps** (25 ≠ 23.976).
2. **بصمة التوقيت**: ينزّل أفضل المرشحين ويقارن أزمنة ظهور الأسطر بترجمة مرجعية مطابقة للنسخة (بعد طرح احتمال التطابق بالصدفة). الأزمنة المتطابقة ترفع النسبة ولو اختلف الاسم، والمختلفة تخفضها.
3. **مدة الفيلم**: آخر سطر في الترجمة يُقارن بمدة الفيلم من Cinemeta لكشف ترجمة نسخة ممدودة أو ناقصة.

**مزامنة تلقائية 🔧**: إن اكتشف فرق fps (مثل 25→23.976) أو إزاحة ثابتة، يعيد الخادم كتابة أزمنة الـ SRT قبل تسليمها (`?r=&o=` على رابط الترجمة).
في الإعدادات: تشغيل/إيقاف التحليل العميق والمزامنة، وأقل نسبة تطابق للربط التلقائي. الواجهة داشبورد بأقسام جانبية وشاشة ترحيب «مرحبتين» وحلقة ثلاثية الأبعاد للمصادر، وتدعم الوضع الفاتح والداكن ووضع النظام. لغة الترجمة العربية فقط 🇸🇦.

## الإيموجي
الصفحة تحمّل الإيموجي (⭐ 🇸🇦 ☀️ 🌙 💻) من روابط dima.tools، وإن تعذّر تستخدم النسخ المحلية في `frontend/emoji/` (star, flag, sys, dark, light, wave, home, cfg, run, src, sub, mat, ins — بصيغة png). استبدل هذه الملفات بنسختك لتصير محلية بالكامل.
الاختبارات: `npm test` (وملف `test/e2e.js` بخوادم وهمية). التحليل العميق لا يستهلك حصة تنزيل OpenSubtitles.

## الإصدار 3.1: منطق أقوى
**مصادر جديدة**: MediaFusion (نسخ، الصق رابط manifest من صفحة إعداده) وOpenSubtitles Homes (ترجمة عربية جاهزة بدون مفتاح، مفعّل افتراضياً).

**مطابقة أذكى**
- النسبة صارت «احتمال تطابق التوقيت»: المصدر (قرص/ويب/تلفزيون) والمنصة والـ fps والنسخة هي الأساس، لا اسم المجموعة وحده. WEB-DL من نفس المنصة يتطابقان غالباً حتى مع اختلاف المجموعة، واختلاف المنصة يخفض النسبة.
- استخراج اسم الإصدار من وصف الإضافات (سطر 📂/📄)، وتوحيد أسماء المجموعات (YIFY=YTS، وإزالة وسوم [rarbg]).
- استبعاد ترجمات الأجزاء الأجنبية (forced) وتخفيض الآلية.

**تحليل توقيت أقوى**
- كشف الإزاحة بمدرّج تكراري لفروق الأزمنة: يلتقط الإزاحة حتى لو نقصت أسطر المقدمة، ويصحّح الإزاحات الصغيرة المحسوسة (نحو نصف ثانية).
- إصلاح انحراف السرعة غير المعروف (نسبة غير موجودة في جدول الـ fps).
- **إجماع الترجمات**: إن لم يوجد اسم مطابق، تُقارن الترجمات ببعضها وتُرفع أكبر مجموعة متفقة التوقيت.
- كل ترجمة إضافة (OpenSubtitles v3 وHomes وغيرها) صارت قابلة للتصحيح عبر الخادم (`/sub/u/`).
- الطبقة العميقة تعمل أيضاً عند طلب الترجمة من المشغّل (مع filename).

**مزامنة تلقائية لكل الترجمات**: كل ترجمة تُضبط على مرجع (اسم مطابق، أو إجماع الترجمات، أو أفضل ترجمة سليمة)، وتُصحّح إزاحتها وسرعتها عبر الخادم قبل التسليم. تُزال النسخ المكررة من مزوّدين مختلفين. إضافة `Anseb - Subtitles` تفعل الشيء نفسه حتى بدون اسم ملف. ترجمات OpenSubtitles.com لا تُحلَّل افتراضياً لحماية حصة التنزيل، وفعّل الخيار في صفحة دقة التطابق لشملها.

**فحص الإضافات**: يعيد المحاولة، يجرّب الرابط بالشكلين `|` و`%7C`، ويطلب ترجمات عنوان معروف كبديل. وللمصادر المعروفة (مثل OpenSubtitles Homes) يظهر تحذير أصفر بدل الخطأ الأحمر إن تعذّر الفحص.

**فحص المحتوى**: لغة خاطئة (إنجليزي موسوم عربي)، ترميز تالف (علامات ؟)، ترجمة شحيحة الأسطر لمدة الفيلم: تُخفض نسبتها وتُستبعد من الإرفاق. ويُصلح الترميز المزدوج لليونيكود تلقائياً.

**ترتيب النسخ**: معدل البت مقابل مدة الفيلم، تورنت بلا بذور، ملفات مزيفة الحجم، ⭐ لأفضل نسخة بين كل المصادر، وبدائل ترجمة من مزوّدات مختلفة.

**RTL**: خيار لإصلاح اتجاه الأسطر العربية التي تبدأ بشرطة أو رمز.

## الإصدار 3.2: المسلسلات القديمة والكرتون (The Simpsons وأمثالها)
طبقات جديدة تعمل بالتوازي مع التوقيت والمحتوى:
- **طبقة الهاش (Hash-Based):** يُمرَّر `videoHash` و`videoSize` و`filename` من Stremio إلى كل إضافات الترجمة (OpenSubtitles v3 وHomes…). ترجمة OpenSubtitles المطابقة للهاش تُنزَّل دائماً وتصبح المرجع الذي تُضبط عليه الباقي، واسمها يكشف النسخة الحقيقية للفيديو حين لا يصل filename.
- **Release Group و S/E:** قراءة أقوى للحلقة: `S01E06` · `S01 EP06` · `1x06` · `Season 1 Episode 6` · `E01-E02` (حلقة مزدوجة) · حزم المواسم · الترقيم المطلق للأنمي (`- 123`). تُقرأ مجموعة الأنمي `[SubsPlease]` أيضاً. الحلقة الخاطئة تُسقَط، والترقيم المطلق يُخفَّض ولا يُقطع.
- **نص ضبابي وضجيج (Fuzzy/Noise):** مقارنة كلمات العنوان تتسامح مع الجمع والأخطاء (simpsons ≈ simpson). وسطور الإعلانات وأسماء المواقع والأرصدة تُحذف قبل تحليل التوقيت حتى لا تشوّه أول/آخر سطر.
- **احتياط المدة (Duration):** عند غياب مرجع توقيت: قرب آخر سطر من المدة المتوقعة يرفع الترجمة أو يخفضها. وإن لم تتوفر مدة من Cinemeta (شائع في المسلسلات القديمة) تُستنتج من وسيط ترجمات الحلقة. مدة بضعف المتوقع (ترجمة مدموجة) تُرفض. تسامح أكبر للمسلسلات (إعلانات داخل المدة).
- **نسخ قديمة:** XviD/DivX وTVRip وPAL/NTSC وDVD لنفس المنطقة تتشارك التوقيت. أسماء الترجمة المجردة («The Simpsons S05E10») تُعامل كـ«غير معروفة» لا كضعيفة. ذيل الأرصدة البعيد لا يفسد قراءة المدة.
- تصحيح نسبة 25/23.976 يعمل تلقائياً لكل ترجمة (PAL).

## كيف يعمل
1. يجمع النسخ من المصادر ويرتبها حسب جهازك (4K/HDR/Atmos) وجاهزيتها.
2. يجمع الترجمات من كل المصادر ويحسب نسبة تطابق كل ترجمة مع كل نسخة (مجموعة الإصدار، المصدر، الدقة، الترميز، الحلقة، السنة، النسخة الممدودة).
3. يرفق أفضل ترجمة بالنسخة نفسها، فتظهر في المشغّل عند التشغيل. الترجمات المضغوطة (zip) تُفك وتُحوَّل إلى SRT بترميز UTF-8 عبر الخادم.
4. عند التشغيل يعيد ترتيب الترجمات حسب اسم الملف الفعلي الذي يرسله ستريمو.

## كل مصدر بنسخه الخاصة
النسخ **لا تُدمج** بين المصادر. كل مصدر يظهر باسمه ويحمل نسخه وترجماته وأرقامه (Seeders/Cached) الخاصة، ولا يظهر `Torrentio+Comet+Comet` مرة ثانية. أفضل نسخة في كل مصدر تأخذ 🏆، والحد الافتراضي 5 نسخ لكل مصدر (`top` في الإعدادات حتى 20).

طريقتان للتثبيت (اختر وحدة فقط):
1. **رابط واحد**: إضافة «Anseb ⭐» وتظهر نتائجها بأسماء `Anseb - Torrentio` و`Anseb - Comet` و`Anseb - StremThru`.
2. **إضافات منفصلة**: من بطاقة «ثبّت كل مصدر لوحده» تثبّت `Anseb - Torrentio` و`Anseb - Comet` و`Anseb - StremThru` كإضافات مستقلة في قائمة إضافات ستريمو. وفيها إضافة اختيارية `Anseb - Subtitles` تعيد ترتيب الترجمة حسب اسم الملف الفعلي عند التشغيل.

يظهر لكل نسخة:
```
Anseb - Torrentio
4K
🏆 اسم الفيلم/المسلسل · المصدر · الترميز
🔊 Audio: ...
📺 4K: Yes ✅ / No ❌
💬 Subtitle: Arabic · مدمجة ✅ / خارجية 94% ✅
💾 18.3 GB  👤 120  📡 Torrentio
```
«مدمجة» تُستنتج من اسم النسخة (علم/كلمة اللغة)، فهي مؤشر وليست فحصاً لمسارات الملف.
لتفعيل الترجمة تلقائياً اختر لغتك في Stremio ← الإعدادات ← المشغّل ← لغة الترجمة.
